# guppy

A fast, keyboard-driven terminal UI for Google Tasks.

```
 ▏                                ▏
 ▏   Lists (2)                    ▏   Personal                       2/4
 ▏                                ▏
 ▏    Personal                    ▏   ☑  Buy milk
 ▏    Work                        ▏   ☐  Write report
 ▏    Shopping                    ▏     └ ☐  Draft outline
 ▏                                ▏   ☐  Call mom

  tab switch · space toggle · a add · A subtask · ? help · q quit
```

## Install

macOS / Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/kartikssj/guppy/main/install.sh | sh
```

Or download a binary from
[Releases](https://github.com/kartikssj/guppy/releases), or build from source.

## Privacy in one line

guppy runs entirely on your computer, talks only to Google's Tasks API, and
collects nothing — no analytics, no telemetry, no servers on our side.
